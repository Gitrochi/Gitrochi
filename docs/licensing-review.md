## 기존 MIT 권리와 전환 한계

MIT로 적법하게 공개된 코드에는 판매·수정·배포·재허락 권한이 이미 부여되어 있습니다. 새 문서로 이를 소급 회수하거나 기존 MIT 코드만으로 만든 파생 프로젝트를 전면 금지한다고 주장할 수 없습니다. 새 버전에 과거 코드가 포함되더라도 그 코드에 대한 기존 권리는 남습니다. [MIT 원문](https://opensource.org/license/mit)

새 제한은 권리자가 동의해 새 조건으로 제공하는 범위에만 적용할 수 있습니다. 개별 기여자에게 받은 권한, 기존 파일별 라이선스 및 고용주 권리를 확인해야 합니다. 과거 PR 제출만으로 새로운 CLA 동의를 추정하지 않습니다. 원하는 전면적인 파생 배포 금지를 기존 MIT 이력 전체에 달성할 수 있다는 보장은 없습니다.

공개 GitHub 저장소의 열람·서비스 내 포크 권리는 별도로 보존합니다. PR 목적 기여 포크의 허용 범위와 플랫폼 약관의 권리는 구분합니다. [GitHub 약관 D.5–6](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service)

이 정책은 배포 제한이 있는 **source-available** 정책입니다. 자유로운 재배포와 파생 배포를 요구하는 OSI의 오픈소스 정의에 맞는다고 표시하지 않습니다. [OSI 정의](https://opensource.org/osd)
